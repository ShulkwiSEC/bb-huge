opencode-browser Plugin — An OpenCode-native plugin that replaces both Playwright MCP and mitmproxy MCP by integrating Browser MCP directly into OpenCode via a Chrome/Edge extension; it injects speed-oriented guidance into the model prompt, annotates slow tools (snapshot/screenshot/wait) with perf hints, preserves browser context across session compactions, and recovers from connection drops instantly — to use it, run npx opencode-browser init to auto-configure opencode.json, install the Browser MCP Chrome extension from https://browsermcp.io/install, then just describe browser tasks naturally (e.g. "navigate to target.com, fill the login form, screenshot the response"); if the browser disconnects, re-enable the extension and retry immediately (no backoff delay), and if tools aren't available restart OpenCode after config changes.
